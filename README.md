## Environment Setup

### 1. Clone the repository

```bash
git clone https://github.com/Kevinsama115/DMU-DL2026.git
cd DMU-DL2026
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment

**macOS / Linux**

```bash
source .venv/bin/activate
```

### 4. Install the required libraries

```bash
pip install numpy pandas matplotlib torch torchvision jupyter
```

_Some notebooks may require additional libraries depending on the assignment._

### 5. Start Jupyter Notebook

```bash
jupyter notebook
```
